Notifications

A desktop notification when a window is projected to land past its limit — and then quiet for as long as you say.

  • One at a time. Inside the interval nothing is sent, even if the window crosses the line again.
  • Only while a dashboard tab is open. The tab can be buried, but nothing runs in the background.
  • Kept in this browser. Nothing leaves the machine.

Auto continue

When a limit reaches 100% and your sessions stop, they pick up again by themselves once it resets.

    • Waits inside each session. The session-tracker plugin's hook sits out the reset in the session that stopped, so no tab or menu bar has to stay open — only the session.
    • Once per stop. A session that hits the limit again waits for the next reset rather than retrying in a loop.
    • Any terminal. Claude Code wakes the session itself, so it works in VS Code, Ghostty, tmux or anywhere else.
    • Same switch as the menu bar. Kept by the tracker, not this browser, so turning it off anywhere turns it off everywhere.
